## AI大模型

### 本地化部署
#### 硬件指南
首先GPU不是显卡，它是显卡的核心组件。大模型需要强大的算力来生成文本、图像、视频等内容，训练这样的模型需要的是GPU+计算架构（比如，NVIDIA的GPU和针对自己GPU设计的CUDA计算架构）90%以上的模型训练或推理都需要GPU的支持。  

##### 计算机组件
八大组件：CPU、散热器、主板、内存、硬盘、显卡、电源、风扇、机箱  
个人电脑： 典型配置是单GPU或双GPU（反正不超过4个）
###### CPU
CPU选择标准：一般一个GPU对应2-4个CPU核数  
一般搭配：NVIDIA GeForce RTX 3090 * 2 搭配 Intel Core i7-13700 or AMD 5900 X
###### 散热器
CPU散热器：水冷和风冷，水冷>风冷
看CPU是否超频，是就需要水冷，不是风冷就行
###### 主板
根据GPU和CPU级别选择：
- Intel：Z系列（高端）、B系列（中端）、H系列（低端）
-  AMD：X系列（高端）、B系列（中端）、A系列（低端）

科普：什么是BIOS（basic input/output system）
BIOS是主板上的一个小芯片，可以看作是电脑启动时最先运行的软件，负责初始化和检测电脑硬件。
BIOS模式中传统的MBR（master boot record）模式和新式UEFI（unified extensible firmware interface）模式会对安装双系统的方式产生影响。因为两种模式在分区表、启动过程和系统安装方面有所不同：
1. 分区表：MBR分区表只支持最多4个主分区，或3个主分区加一个扩展分区，扩展分区可以分成更多的逻辑分区，而UEFI：使用GPT（GUID partition table）分区表，支持多达128个分区，没有MBR中的分区限制
2. 启动过程：MBR依赖BIOS来识别启动设备，然后读取MBR中的引导加载程序来加载操作系统，而URFI提供一个启动管理器，意味UEFI固件可以直接启动EFI文件（如windows的bootmgfw.efi或Linux的GRUB）
3. 安全性和兼容性：UEFI支持安全启动（secure boot），这可以阻止非授权的操作系统加载。在安装双系统时，需要在UEFI设置中禁用安全启动，用于确保电脑只能启动原装系统。如果电脑重装了其他系统，那么这个系统是启动不了的。说白了，就是垄断，所以安装完其他系统，必须关闭安全启动，新系统才能启动，而MBR不支持安全启动。

如何检查自己电脑是哪个模式？
`win+r`, input `msinfo32`
###### 硬盘
1. 看接口类型，主流有两种：SATA和M.2
   - SATA：体积大，速度慢，最高传输速度600MB/s
   - M.2：硬盘小，用新的硬盘协议，速度4GB/s
2. 看协议。M.2接口的固态硬盘分别为SATA协议和NVME协议
   - SATA协议：本质是采用M.2接口的SATA盘，速度慢
   - NVME协议：速度快
3. 看PCle等级。等级越高传输速度越快，现在有PCle 5.0、PCle 4.0、PCle 3.0，一般来说4.0就行
###### 内存
- 由于数据生成器（dataloader）的存在，数据不需要加载到内存中，因此通常不是大问题
- 建议内存容量是GPU显存的一到两倍即可。例如，单卡GPU，至少16GB，四卡GPU，至少64GB。
- 注意检查主板是否支持内存的型号及可插的槽位。
- 注意检查cpu、主板是否支持选择的内存频率，内存的频率受限于cpu和主板的限制
###### 电源
电源的瓦数要满足整机的功耗。计算方法：CPU和GPU的TDP功耗相加，然后乘以2。例如：一个65w的cpu加上一个125w的gpu，合适的电源为400w或450w。  
ps：双卡最好买1000w以上，四卡最好买1600w以上
###### 机箱
- 核对主板与机箱尺寸的匹配性
- 确认机箱支持显卡尺寸，建议高出显卡长度至少30毫米
- 检查cpu散热器是否能装下
- 检查电源和机箱的尺寸

##### 硬件配置的选择标准
例如ChatGLM-6B模型为例，官方给出的硬件配置说明如下：
| 量化等级   | 推理时GPU显存占用  | 微调时GPU显存占用   | 最低显卡配置 | 显卡显存  |
|-----------|--------------------|--------------------|-------------|-----------|
| 单精度    | 20G                | 22G                | 4090        | 24G       |
| 半精度    | 13G                | 14G                | 3090        | 24G       |
| INT 8     | 8G                 | 9G                 | 2080Ti      | 11G       |
| INT 4     | 6G                 | 7G                 | 2060s       | 8G        |


量化等级（Quantization Levels）指的是在计算机中表示数据时使用的不同精度或数据格式。可以帮助减少模型的计算和存储需求，常用于推理阶段的加速。
双精度：FP64 64位浮点，干啥都行。
单精度：FP32 32位浮点，常用于训练和精度要求高的推理。
半精度：FP16 16位浮点，常用于加速推理和训练。
INT8：8位整数，常用于高效推理，特别是在移动和嵌入式设备上。
INT4：4位整数，适用于极限条件下的高效推理，精度损失可能较大。

精度低会导致模型在推理阶段的预测结果不准确（例如图像分类，语音识别）

##### 硬件组合分类
1. 纯CPU（不推荐）
2. 单机单卡：适用于个人使用和中等计算负载场景
3. 单机多卡：使用于高计算负载场景
4. 多机配置：多台计算机进行集群计算

省钱的话，可以用单机多卡，比如进行多轮对话，使用3090双卡（此时显存48G），但是但凡需要双精度FP64，那肯定需要A100/A800卡
